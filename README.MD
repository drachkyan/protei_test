## Эмулятор смс сервиса для мобильной сети

# Сборка и запуск

Для сборки нужно установить зависимости

```
sudo apt install liburing-dev pkg-config libsqlite3-dev
```

Сборка проекта

```
cmake -B build .
cmake --build build
```

Запуск (пока что доступны только следующие аргументы запуска)

Запуск сервера
``` 
./build/mnc_s -p 8085 -epc epc.json -bases bases.json
```

Запуск клиента
``` 
./build/ue -p 8085 -i 0.0.0.0 -imei 158863118273320 -imsi 12345601112233 -msisdn 89991112233 -x -10
```

# Структура программы

В корне лежат две папки UE и MNC отвечающие за клиентскую и серверную части соотвественно.
Также есть папка model в которой лежат общие для сервера и клиента модели (ue.context, коды ошибок и тд)

# UE
UE состоит из модулей Exchange и Menu. Exchange представляет собой модуль обмена информацией с сервером. 
Меню это UI для ввода команд, который вызывает соотвествующие методы exchange
Также в программе присутствует дополнительный модуль Settings для парсинга и хранения аргументов командной строки

# MNC
MNC-S состоит из модулей ENODE, MME и XLR. 
ENODE - это эмулятор базовой станции, вся его суть это трансляция запросов на ММЕ (в будущем также будет хранить в буфере смс)
также предоставляет возможность измерить силу подключения

MME - эмулятор узла управления мобильной сети. Осуществляет связь с XLR, а также в будущем будет отвечать за связь енод 
между собой для обмена смс

XLR - модуль базы данных, эмулирует VLR и HLR. Реализует необходимые запросы через sqllite orm

Также есть дополнительный модуль network, реализующий 2 архитектурных слоя - 
транспортный и гейтвей (в данном контексте это прослойка между транспортным слоем и бизнес логикой)
